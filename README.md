# Google Cybersecurity Professional Certificate: Incident Response Portfolio

## Project Overview
This repository contains a collection of three cybersecurity incident reports completed as part of the Google Cybersecurity Certificate.


## Projects
### 1. ICMP Flood Attack Response using NIST CSF
**Description:** Analyzed an ICMP Flood attack and applied the NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover) to develop an incident response plan.
01_ICMP_Flood_Attack_Analysis.pdf

**Skills Demonstrated:**
* Incident Response
* NIST Cybersecurity Framework
* ICMP Flood Attack analysis

### 2. SYN Flood Attack Investigation and Incident Analysis
**Description:** Investigated a SYN flood attack by analyzing logs to identify the cause of a web server DoS attack.

**Skills Demonstrated:**
* DoS Attack identification
* TCP/IP Networking
* SYN Flood Attack analysis

### 3. DNS & ICMP Network Traffic Investigation
**Description:** Examined DNS and ICMP traffic logs with tcpdump to identify the root cause of a network connectivity issue.

**Skills Demonstrated:**
* Network Traffic Analysis
* DNS Troubleshooting 
* Tcpdump Analysis
